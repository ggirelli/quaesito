# Disclaimer: this app is fully vibe coded

Quaesito was written entirely by an AI coding assistant, Claude (made by Anthropic), working in
[Claude Code](https://claude.com/claude-code). Its code, tests, documentation, release scripts and
this disclaimer were generated by the assistant in conversation with the project's maintainer, who
described what they wanted, tried the results and asked for changes. No line of it was written by
hand.

## What that means

- **It has been tested, not audited.** Every change was checked by the assistant with automated
  tests (`just check`) and by driving the app in a real browser, and the maintainer played with it.
  Nobody has reviewed the code line by line the way a careful human-written project would be.
- **Expect rough edges.** Bugs that tests and play sessions did not reveal are likely. Please
  [report them](https://github.com/ggirelli/quaesito/issues).
- **Mind the security model.** Quaesito is meant for a trusted local network during a game night
  (see [SECURITY.md](SECURITY.md)). Do not expose it to the internet, and do not rely on it for
  anything that matters more than bragging rights.
- **No warranty.** As the [licence](LICENSE) says, the software is provided "as is".

## Why say it

Because it is true, and because you should know how the software you run was made. The commit
history shows the whole process: each commit is co-authored by the assistant.
