# How it was made

!!! warning "Fully vibe coded"
    Quaesito was written entirely by an AI coding assistant: Claude, made by Anthropic, wrote the
    code, tests, documentation and release scripts in conversation with the project's maintainer,
    who described what they wanted, tried the results and asked for changes. No line of it was
    written by hand.

- **It has been tested, not audited:** every change was checked with automated tests and by
  driving the app in a real browser, but nobody has reviewed the code line by line.
- **Expect rough edges:** please [report bugs](https://github.com/ggirelli/quaesito/issues).
- **Keep it on your local network** for game nights; do not expose it to the internet.
- **No warranty:** the software is provided "as is" under the MIT licence.
