# Running the game

Press **▶ Start** next to a quiz. Put the big screen on the TV, full screen with ++f11++. Teams
scan the QR code, or open the address shown and type the game code, then pick a name and a
picture.

| To… | Press |
|---|---|
| move on | the big button, ++arrow-right++, ++page-down++ or ++n++ (presentation clickers work) |
| go back | ++arrow-left++, ++page-up++ or ++b++: the previous slide, results or podium step, or out of a question opened by mistake |
| pause | ++p++ or ⏸: the clock, the music and the automatic advance stop |
| give more time | **+10 s** while a question is open |
| rename or remove a team | **Teams** in the top bar |
| mute sound effects | :material-volume-high: in the top bar |

## Judging

For typed answers, the reveal groups identical answers: mark each group ✓ full, ½ half or ✗ no
points, and add a bonus or malus with − and +. Standings update straight away.

![Judging typed answers on the big screen](screenshots/host-judging.webp)

## If something goes wrong

- **A team typed a silly name:** rename it, or remove it, from **Teams**.
- **The doorbell rings:** pause with ++p++; answers already sent still count.
- **You moved on by mistake:** go back with ++arrow-left++. Leaving a question that is still open
  cancels it, and it is asked again later.

!!! tip "Crashes and restarts"
    If the laptop goes to sleep or the server restarts, the game comes back paused where it was,
    with the same time left; phones and the big screen reconnect by themselves. Press
    **▶ Resume** to carry on.
