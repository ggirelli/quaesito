# Assets

Assets that would improve Quaesito but that I cannot produce myself. Each entry has a prompt to
paste into ChatGPT (or another image generator), the file name and where to put it. None of them
is required: the app works without them.

Brand colours for every prompt: amber `#FFB703`, deep indigo `#14121F`, off-white `#F4F1FF`.

## Wanted

### GitHub social preview (optional)

- **File:** `assets/brand/social-preview.png`, 1280×640 PNG
- **Used by:** GitHub repository settings → Social preview (uploaded by hand, not referenced by code)
- **Prompt:**

  ```
  Create a 1280×640 social preview banner for "quaesito", a self-hosted quiz game for friends:
  a big screen shows questions and teams answer on their phones. Deep indigo #14121F background.
  On the left, the logo: a bold amber (#FFB703) rounded question mark whose top loops like a "q",
  next to the lowercase serif word "quaesito" in amber. On the right, a playful flat-vector
  illustration of a TV showing four coloured answer tiles (pink #EF476F, blue #118AB2, yellow
  #FFD166, green #06D6A0) and three phones held up by hands. Flat vector, no gradients, no
  photorealism, no extra text besides "quaesito" and the tagline "Quizzes among friends." in
  off-white #F4F1FF.
  ```

### Lobby illustration (optional)

- **File:** `assets/illustrations/lobby.svg` (preferred) or `lobby.png`, transparent background, about 800×600
- **Used by:** the big-screen lobby while waiting for teams (not wired up yet; I will add it when the file exists)
- **Prompt:**

  ```
  Flat vector illustration on a transparent background, about 800×600: a cosy group of friends on
  a sofa holding phones up towards a TV that shows a big amber question mark. Simple geometric
  shapes, rounded, playful. Palette limited to amber #FFB703, deep indigo #14121F, off-white
  #F4F1FF and accents pink #EF476F, blue #118AB2, green #06D6A0. No text, no gradients,
  no photorealism. Must read well on a dark #14121F background.
  ```
